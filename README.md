# CJ푸드빌 재무제표 및 재무비율 분석

## 분석 기준
- 대상: CJ푸드빌(주)
- 기준: **연결 기준**
- 기간: 2022~2025년
- 금액 단위: 백만원
- 분석 기준일: 2026-09-21
- 첨부된 `재무제표 및 재무비율 실무 가이드`의 계산식과 분석 순서를 적용

## 파일
- `financial_data.csv`: 주요 재무데이터 원자료
- `financial_ratios.csv`: 계산된 주요 재무비율
- `financial_analysis.md`: 추세 및 비율 분석
- `sources.md`: 자료 출처와 데이터 기준

## 주의
첨부파일은 CJ푸드빌의 원재무제표가 아니라 재무비율의 정의·계산·해석을 설명하는 실무 가이드입니다. 따라서 CJ푸드빌 원자료는 공시/회사 자료를 별도로 확인하여 입력했습니다.
